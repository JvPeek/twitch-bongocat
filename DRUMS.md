## New Drums in bongo cat 
This version added 4 drumsounds to the classic Bongo cat Sounds 
### how to use ?
Drums on this Keys
 * X - Base drum
 * C - Snara drum
 * B - Closed Hi-Hat
 * N - Open Hi-hat
### Why all this
standart Bongo cat had just some random and to loud persusions sounds, but some keys are still usable on the keyboard so i had to fil it!
### why not all keys 
The last row of key are already used by otehr Bongo cat features like this:
 * Y as an altrnative for Z conflict in DE and US layout.
 * V as lower Octave value for Bongo+
 * M as "Mau" sound in all versions  
### Midi Notes corrosponding to Drums
In case you use Midi files as source for your notes, here are note values of Midi channel 10 corresbonding to Bongo cat:
 * Base drum     C1  36  - X
 * Snara drum    E1  40  - C
 * Closed Hi-Hat F#1 42  - B
 * Open Hi-hat   A#1 46  - N
